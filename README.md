# Mis Finanzas

Proyecto integrador del curso **Desarrollo de Aplicaciones Móviles con React Native** (FPUNA).

App para controlar gastos e ingresos: registro de movimientos por categoría, balance, estadísticas y foto del comprobante con la cámara.

## Funcionalidades
- Formulario controlado de gastos/ingresos con validación (Semana 3)
- Navegación con Bottom Tabs + Stack para el detalle (Semana 4)
- Listas con FlatList (Semana 5)
- **Cámara (Cap. 6):** adjuntar la foto del comprobante a cada movimiento con `expo-camera`, pidiendo el permiso solo al pulsar "Adjuntar comprobante"

## Tecnologías
Expo · React Native · React Navigation · expo-camera · expo-linear-gradient

## Ejecutar
```bash
npm install
npx expo start
```
